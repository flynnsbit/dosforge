IBM PC-DOS 1.0 / 1.1 install assets
====================================

Staging area for IBM PC-DOS 1.0 and 1.1 (the very first PC-DOS
releases, contemporaneous with the original IBM PC and PC/XT).

Expected files: 5.25" SS/DD floppy images (160 KiB).

Status: dosforge does not yet ship a boot-mode=pcdos1. Drop install
media here so it's ready when support lands. Until then the tool
will report "no install images found" if anyone points it at this
folder.

Source (WinWorldPC): "IBM PC-DOS 1.00 / 1.10" archives.

This folder tracks readme.txt only; the install media itself is
gitignored.
