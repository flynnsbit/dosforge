IBM PC-DOS 2.0 / 2.10 install assets
====================================

Staging area for IBM PC-DOS 2.0 (IBM PC/XT era — first version
with subdirectory support and hard-disk capability) and PC-DOS 2.10
(the XT/Portable revision).

Expected files: 5.25" DS/DD floppy images (320 KiB or 360 KiB).

Status: vhdmaker does not yet ship a boot-mode=pcdos2. Drop install
media here so it's ready when support lands. Until then the tool
will report "no install images found" if anyone points it at this
folder.

Source (WinWorldPC): "IBM PC-DOS 2.00 / 2.10" archives.

This folder tracks readme.txt only; the install media itself is
gitignored.
