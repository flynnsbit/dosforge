Digital Research DR-DOS 5.0 install assets
==========================================

Staging area for Digital Research DR-DOS 5.0 (the original DR-DOS
release that prompted Microsoft's MS-DOS 5.0 development).

Expected files: 3.5" 1.44 MiB or 5.25" 1.2 MiB install diskettes.

Status: vhdmaker does not yet ship a boot-mode=drdos5. Drop install
media here so it's ready when support lands. Until then the tool
will report "no install images found" if anyone points it at this
folder.

Source (WinWorldPC): "Digital Research DR-DOS 5.0".

This folder tracks readme.txt only; the install media itself is
gitignored.
