IBM PC-DOS 5.00 / 5.02 install assets
=====================================

Staging area for IBM PC-DOS 5.x (IBM's branded counterpart to
MS-DOS 5.0; introduced HMA/UMB support and the DOSSHELL).

Expected files: 3.5" 1.44 MiB install diskettes.

Status: dosforge does not yet ship a boot-mode=pcdos5. Drop install
media here so it's ready when support lands. Until then the tool
will report "no install images found" if anyone points it at this
folder.

Source (WinWorldPC): "IBM PC-DOS 5.00 / 5.02" archives.

This folder tracks readme.txt only; the install media itself is
gitignored.
