IBM PC-DOS 6.10 / 6.30 install assets
=====================================

Staging area for IBM PC-DOS 6.x:
  6.10 — IBM's first PC-DOS 6.x, contemporary with MS-DOS 6.x
  6.30 — improved version with PCMCIA support and bug fixes

Expected files: 3.5" 1.44 MiB install diskettes.

Status: dosforge does not yet ship a boot-mode=pcdos6. Drop install
media here so it's ready when support lands. Until then the tool
will report "no install images found" if anyone points it at this
folder.

Source (WinWorldPC): "IBM PC-DOS 6.10 / 6.30" archives.

This folder tracks readme.txt only; the install media itself is
gitignored.
