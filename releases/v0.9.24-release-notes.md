# dosforge v0.9.24

## Curated FreeDOS `C:\FDOS\BIN\` payload

Closes the v0.9.23 follow-up: FreeDOS now gets the same curated
treatment as legacy DOS modes. `_select_minimal_freedos_payload`
used to copy the entire FreeDOS `BIN/` tree verbatim
(`shutil.copytree`), which staged ~60 files including a 1.2 MB
`curl.exe`, an HTML help viewer, multiple debug variants, kernel
binaries, DOS-extender stubs, and the FreeCOM source tree.

### Changes

**New `_FREEDOS_BIN_USEFUL_FILES` whitelist** (default-deny) gates
what gets copied from `BIN/` into the staged payload:

| Category | Files |
|---|---|
| Editor / text tools | EDIT.EXE+HLP, EDLIN.EXE, SED.EXE, LESS.EXE+HLP |
| File management | ATTRIB, XCOPY, MOVE, DELTREE, TREE, TOUCH, COMP, FC |
| Disk management | FORMAT, FDISK, LABEL, CHKDSK, SYS |
| Memory drivers | MEM, FDXMS, **HIMEM**, **HIMEMX**, **EMM386** |
| Search / sort | FIND, SORT, GREP |
| Path / scripting | ASSIGN, SUBST, SWSUBST, CHOICE, DOSKEY |
| Display / console | MODE, NANSI |
| Process / system | DEBUG, DEVLOAD, SHARE, SVER, WHICH |
| Mouse drivers | CTMOUSE, MOUSE |
| **Game-relevant (sound + CD)** | **SB, SBPMIXER, SBPMIXER.DRV, PLAYCD, MSCDEX, SHSUCDX** |

Sub-directories under `BIN/` (e.g. `FREECOM/` source tree) are
dropped wholesale — FreeDOS users never run them at a DOS prompt.

### Bloat now filtered out

| Category | Examples |
|---|---|
| Networking | curl.exe (1.2 MB), curllite.exe (552 KB), ping.exe |
| HTML / docs | htmlhelp.exe, bookshlf.exe |
| Multiple debug variants | debugb.bin, debugx.com, debxxvdd.dll, ldebugb.exe |
| Kernel binaries | kernl386.sys, kernl86.sys, kernl86n.sys |
| DOS-extender internals | dos32a.exe, stub32a.exe, stub32c.exe |
| Variant duplicates | edlin32.exe, fdxmst.sys, fdxxms.sys, fdxxmst.sys |
| Unix-style oddities | head.com, tee.exe |
| Niche helpers | _choice.exe, _label.exe, _tee.exe, lesskey.exe, wcd.exe, sc.exe, ss.exe |
| Internationalization | country.sys, display.exe |
| Drivers (non-user) | setver.sys |
| Sub-tree | FREECOM/ (FreeCOM source code) |

### Verified end-to-end (Windows, 128 MiB FAT16 FreeDOS VHD)

```
=== FDOS/BIN ===
35 files, ~1 MB total
zero bloat (curl/htmlhelp/kernl/etc. all absent)
```

### Files changed

- `src/dosforge/boot.py` — added `_FREEDOS_BIN_USEFUL_FILES`
  whitelist; rewrote `_select_minimal_freedos_payload` step 1 to
  filter `BIN/` files instead of `shutil.copytree` the whole tree;
  skips nested subdirs under `BIN/`.
- `tests/test_boot_assets.py` — new
  `test_select_minimal_freedos_payload_curates_bin_to_whitelist`
  smoke test; updated `test_freedos_filter_keeps_bin_recursively`
  to assert the new policy (whitelisted files stay,
  `FREECOM/subhelper.exe` is dropped).
- `pyproject.toml` + `src/dosforge/__init__.py` — 0.9.23 → 0.9.24
