# dosforge v0.7.14

TUI cosmetic fix — eliminate the empty 1-cell gap to the right of
the `...` browse buttons on path rows.

## Issue

In the TUI Create wizard, the `...` browse buttons (next to Output
path, Boot assets directory, Custom payload directory, and the
file-tools Open / Extract path inputs) appeared to float slightly
left of the path-row's right edge — there was a visible 1-cell of
empty space between the button and the container border instead of
the button sitting flush against the right.

## Cause

The global `Button { margin: 0 1 1 0; }` rule in the Textual
stylesheet set a 1-cell right margin on every button.  The more
specific `.path-row Button { margin: 0 0 0 1; }` rule was meant to
override that to "no right margin", but with Textual's CSS cascade
the shorthand `margin` property wasn't fully overriding the
individual `margin-right` value coming from the global rule — so
the path-row buttons inherited a leftover 1-cell right margin.

## Fix

Replace the shorthand with explicit longhand margin properties in
the `.path-row Button` rule:

```css
.path-row Button {
  width: 5;
  min-width: 5;
  max-width: 5;
  margin-top: 0;
  margin-right: 0;   /* explicit -- overrides the global 1-cell right margin */
  margin-bottom: 0;
  margin-left: 1;    /* keep 1-cell gap between Input and Button */
  padding: 0;
}
```

The button now sits flush against the right edge of every path-row
container (Step 1 boot-assets path, Step 2 output path, Step 3
custom payload, the file-tools Open / Extract rows) while keeping a
1-cell gap between the input field and the button itself.

## Affected widgets (TUI)

- `#create-path-row` — Step 2 Output path
- `#boot-assets-row` — Step 1 Boot assets directory or install image
- `#custom-payload-row` — Step 3 Custom payload directory
- `#open-path-row`, `#extract-row` — File tools tab

## What didn't change

- GUI (`dosforge gui`) — Tkinter layout uses `padx=(8, 0)` and a
  weighted column, button is already flush against the right.
- Path-row geometry, Input width (`1fr`), heights — unchanged.
- All other Button styles (`btn-primary`, `btn-secondary`,
  `btn-destructive`, `btn-ghost` outside path-rows) — unchanged.

## Tests

166/166 focused tests pass (no logic changes; CSS-only fix).
