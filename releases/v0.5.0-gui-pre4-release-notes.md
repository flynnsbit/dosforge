# dosforge v0.5.0-gui-pre4 — title bar follows the dark theme on first paint

Fix: opening the GUI for the first time, the Windows title bar was
rendered in light mode and only switched to dark after the user clicked
away and back to the window. Setting `DWMWA_USE_IMMERSIVE_DARK_MODE`
alone isn't enough — the non-client area only repaints on focus change
unless you kick it explicitly. After setting the attribute we now also
call `SetWindowPos(..., SWP_FRAMECHANGED)` to force the title bar to
redraw immediately with the new theme.
