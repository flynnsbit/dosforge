Digital Research DR-DOS 6.0 install assets
==========================================

Staging area for Digital Research DR-DOS 6.0 (added DPMI / EMM386
support; the DR-DOS that competed head-on with MS-DOS 5.0/6.0).

Expected files: 3.5" 1.44 MiB install diskettes.

Status: dosforge does not yet ship a boot-mode=drdos6. Drop install
media here so it's ready when support lands. Until then the tool
will report "no install images found" if anyone points it at this
folder.

Source (WinWorldPC): "Digital Research DR-DOS 6.0".

This folder tracks readme.txt only; the install media itself is
gitignored.
