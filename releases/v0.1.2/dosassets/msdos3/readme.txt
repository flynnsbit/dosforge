MS-DOS 3.0 / 3.05 / 3.10 / 3.20 / 3.21 install assets (pre-3.30)
================================================================

Staging area for early MS-DOS 3.x releases. MS-DOS 3.30 has its
own folder (dosassets/msdos33/), and Compaq DOS 3.31 lives in
dosassets/compaq331/.

Expected files: 5.25" DS/DD floppy images (360 KiB) for 3.0 / 3.10;
3.5" DS/DD floppy images (720 KiB) for 3.20 / 3.21.

Status: dosforge does not yet ship a boot-mode for pre-3.3 MS-DOS.
Drop install media here so it's ready when support lands. Until
then the tool will report "no install images found" if anyone
points it at this folder.

Source (WinWorldPC): "Microsoft MS-DOS 3.0", "3.10", "3.20", "3.21".

This folder tracks readme.txt only; the install media itself is
gitignored.
