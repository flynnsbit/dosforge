# dosforge v0.8.1

TUI cosmetic fix: reorder the Step 2 (Media) fields so **Output
path** sits directly under **Disk type**.

## Before (v0.8.0)
```
Step 2 — Media
  Disk type            [VHD ▼]
  Disk controller      [Auto-detect from boot mode ▼]
  Output path          [_______________________________][...]
  Geometry source      [Static size ▼]
  ...
```

## After (v0.8.1)
```
Step 2 — Media
  Disk type            [VHD ▼]
  Output path          [_______________________________][...]   ← MOVED
  Disk controller      [Auto-detect from boot mode ▼]
  Geometry source      [Static size ▼]
  ...
```

The path you're about to write to is closer to the disk-type
choice it follows from, which reads more naturally.

## What didn't change

- GUI (`dosforge gui`) layout — the Output card already sits at the
  very top of the form (above Boot, above Media), so Output path
  is visually before Disk type. No change needed.
- Widget IDs, validation rules, formlogic behavior — all unchanged.
- Step 1, Step 3, Step 4, Browse / Tools / Mounts / Utilities tabs
  — unchanged.

## Tests

176/176 focused tests pass (layout-only change; no logic touched).

## Files changed

- `src/dosforge/app.py` — Step 2 widget order in `compose()`.
