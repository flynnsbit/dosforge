# dosforge v0.9.23

## Curated FULL-profile `C:\DOS\` payload for legacy DOS modes

The FULL install profile used to dump every binary the install media
exposed under `C:\DOS\`, which dragged in installer wizards
(`INSTALL.EXE`), multi-user login tools (`LOGIN.EXE`), and
distro-internal drivers (`DEVSWAP.COM`, `SSTORDRV.SYS`) that have no
business on a user's already-installed disk. The new behavior stages
a focused, hand-picked set of utilities a DOS user would actually run
plus everything they need to manage games and configuration.

### Changes

**Expanded whitelist** (`_DOS_CORE_PAYLOAD_UTILITY_CANDIDATES`):

- `ASSIGN.COM` / `ASSIGN.EXE` — drive remap (user-requested)
- `MOUSE.COM` / `DRMOUSE.COM` / `CTMOUSE.EXE` / `MSMOUSE.COM` —
  mouse drivers per-distro (user-requested)
- `MOVE.EXE` — file/dir move
- `SORT.EXE` — text sort
- `TREE.COM` / `TREE.EXE` — directory tree
- `DELTREE.EXE` — recursive directory delete
- `DOSKEY.COM` — command-line editing + history
- `UNDELETE.EXE` — file recovery
- `MSCDEX.EXE` — CD-ROM driver (essential for many DOS games)

**New exclusion list** (`_DOS_CORE_PAYLOAD_EXCLUDED_BASENAMES`)
filters these out even when referenced in the install media's
`CONFIG.SYS` / `AUTOEXEC.BAT`:

| Category | Excluded |
|---|---|
| Installer wizards | `INSTALL`, `SETUP`, `UNINSTAL`, `DELOLDOS`, `OAKINST` |
| Multi-user subsystem | `LOGIN` |
| DR-DOS internals | `DEVSWAP`, `SSTORDRV`, `SSTOR`, `VIEWMAX`, `TASKMAX`, `DOSSHELL` |
| Networking / sharing | `SHARE`, `INTERLNK`, `INTERSVR` |
| Code-page support | `NLSFUNC`, `GRAFTABL` |
| Backup tools | `BACKUP`, `RESTORE`, `MSBACKUP`, `MWBACKUP` |
| Antivirus | `VSAFE`, `MSAV`, `MWAV`, `MWAVTSR` |
| Print spooler | `PRINT` |
| Path / cache helpers | `APPEND`, `FASTOPEN` |
| Other niche | `POWER`, `WINA20`, `MEMMAX` |

### Verified results (Windows, end-to-end)

**DR-DOS 6 FULL** — 20 utilities, 263 KB (was 21 with junk):

> ASSIGN ✓ ATTRIB CHKDSK DISKCOMP DISKCOPY FDISK FIND FORMAT
> LABEL MEM MODE MOVE SORT SUBST ✓ SYS TREE UNDELETE XCOPY ✓
>
> *removed:* INSTALL.EXE, LOGIN.EXE, DEVSWAP.COM, SSTORDRV.SYS

**MS-DOS 6.22 FULL** — 27 utilities including EDIT/QBASIC, DEBUG,
DELTREE, DOSKEY, MSCDEX, all user-requested utilities.

### Out of scope

FreeDOS's `C:\FDOS\BIN\` goes through `_resolve_freedos` which dumps
the entire FreeDOS LiveCD payload (curl, HTML help, multiple debug
variants, ~hundreds of files). Curating that requires separate
logic against the FreeDOS image dump rather than the install-floppy
extractor; tracked as a follow-up.
