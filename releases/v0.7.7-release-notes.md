# dosforge v0.7.7 — TUI dropdown toggle (real fix)

Real fix for the SingleClickSelect dropdown-toggle bug.  v0.7.5
claimed to fix it but didn't — clicking the chevron of an expanded
dropdown still left it open ("refreshed" the dropdown rather than
closing it).

## Root cause

The bug had TWO interacting race conditions, not one:

1. **Open race** (the v0.7.5 fix addressed this):
   ``MouseDown`` opens the overlay, then synthesized ``Click``
   posts ``SelectCurrent.Toggle``, then the parent's handler does
   ``expanded = not expanded`` — flipping back to closed.

2. **Close race** (v0.7.5 missed this):
   When the user clicks the chevron of an *already-expanded*
   dropdown:
   - The overlay loses focus first → ``SelectOverlay.Dismiss(lost_focus=True)``
     → parent's dismiss handler sets ``expanded=False`` (CLOSES)
   - Then ``SelectCurrent.Toggle`` fires → parent's flip handler
     does ``not False = True`` — RE-OPENS

The v0.7.5 flag-based approach only suppressed the parent on the
"just opened via MouseDown" path.  For "already open + clicked
again", the flag was False, so the parent's handler ran, and the
re-open race fired.

## v0.7.7 fix

Always block the parent's Toggle handler with ``event.prevent_default()``
and let the MouseDown + overlay-blur-dismiss pair drive the
expanded state alone:

```python
def _on_mouse_down(self, event) -> None:
    if not self.expanded:
        self.action_show_overlay()  # the only thing that opens
        self._just_opened_on_mouse_down = True

@_textual_on(SelectCurrent.Toggle)
def _single_click_toggle(self, event):
    event.stop()
    event.prevent_default()  # ALWAYS, not conditionally
    self._just_opened_on_mouse_down = False
```

The MouseDown handler opens when closed.  The overlay's natural
blur-dismiss closes when the user clicks anywhere outside the
overlay (including the chevron).  Our Toggle handler does no
state changes — it just suppresses the parent's racy flip.

## Verification

Trace for "click chevron of expanded dropdown":

1. MouseDown on Select widget → ``_on_mouse_down`` → ``expanded=True``
   → no-op (flag stays False).
2. Focus moves to Select widget → overlay loses focus →
   ``SelectOverlay.Dismiss`` → parent's dismiss handler → ``expanded=False``.
3. Click → ``SelectCurrent.Toggle`` → subclass handler:
   ``prevent_default`` → parent's flip is suppressed → STAYS CLOSED ✓

Trace for "click chevron of collapsed dropdown" (first click):

1. MouseDown on Select widget → ``_on_mouse_down`` → ``expanded=False``
   → ``action_show_overlay()`` → ``expanded=True`` (flag=True).
2. Click → ``SelectCurrent.Toggle`` → subclass handler:
   ``prevent_default`` → parent's flip is suppressed → STAYS OPEN ✓

Trace for "click an option in expanded overlay":

1. MouseDown on overlay → no Toggle/Dismiss involved.
2. Click on option → ``SelectOverlay.UpdateSelection`` → parent
   handles → sets value, closes. ✓
