# dosforge v0.9.47

## IBM 8088 boot mode -- 4-way DOS Version picker + new PC-DOS 5 support

User-reported UX gap on the **IBM PC 8088** boot mode: the dropdown
said *"IBM DOS 3.3 / IBM DOS 5.0"* but the install pipeline actually
reads `dosassets/msdos33/` and `dosassets/msdos5/` (Microsoft, not
IBM).  Picking *"IBM DOS 3.3"* and dropping authentic PC-DOS 3.x
diskettes into `dosassets/pcdos3/` silently routed to the MS-DOS
folder instead.

v0.9.47 fixes the mismatch by renaming the field to **"DOS Version"**
and expanding it from 2 to **4 picks** so the label matches what
actually gets installed:

| Pick                | Asset dir            | Filesystem cap          | System files                 |
|---------------------|----------------------|-------------------------|------------------------------|
| MS-DOS 3.3          | `dosassets/msdos33/` | FAT12/16, ≤32 MiB       | IO.SYS + MSDOS.SYS           |
| **PC-DOS 3.x (new)**| `dosassets/pcdos3/`  | FAT12, ≤16 MiB          | IBMBIO.COM + IBMDOS.COM      |
| MS-DOS 5.0          | `dosassets/msdos5/`  | FAT12/16, ≤504 MiB      | IO.SYS + MSDOS.SYS           |
| **PC-DOS 5.x (new)**| `dosassets/pcdos5/`  | FAT12/16, ≤504 MiB      | IBMBIO.COM + IBMDOS.COM      |

Defaults flip automatically on selection: PC-DOS 3.x forces FAT12 +
15 MiB (MFM auto), PC-DOS 5.x stays IDE + 32 MiB.  The Boot assets
directory field on the TUI is also moved **below** the DOS Version
picker so it pre-populates with the right `dosassets/<subdir>` name
after both Step 1 selections are made.

### New: `BootMode.PCDOS5`

PC-DOS 5.x is now a **first-class boot mode** as well as an IBM 8088
sub-version.  CLI:

```bash
dosforge create --boot-mode pcdos5 \
                --format fat16 --size 128M \
                --output /tmp/pcdos5.vhd
```

The pipeline mirrors `pcdos7` and `msdos5`: extracts the WinWorldPC
`IBM PC-DOS 5.00 (1991) (3.5).7z` archive on demand (py7zr,
in-process), boots Disk01.img under QEMU, runs `FDISK /MBR` +
`FORMAT C: /S`, then mcopies the rest of the DOS tools to `C:\DOS\`.
Sets system+hidden attributes on `IBMBIO.COM` / `IBMDOS.COM`.

PC-DOS 5 install media is **user-supplied**: drop the .7z (or
pre-extracted .img files) into `dosassets/pcdos5/`.  The folder's
readme.txt has been updated with the expected layout.

### Back-compat notes

- Old `state.json` files persisted `"dos33"` / `"dos50"` wire values.
  The new `IBMDOSVersion` enum still parses those for back-compat
  -- they map to MSDOS33 / MSDOS5.
- Old `--ibm-dos-version dos33` / `--ibm-dos-version dos50` CLI
  invocations still work (legacy aliases are kept in the argparse
  choices list).
- Pre-v0.9.47 user-organized `dosassets/<root>/dos33/` and
  `dosassets/<root>/dos50/` *subdir* layouts under a custom
  `--boot-assets-path` are still recognized; the resolver now tries
  both the canonical name and the legacy alias.

### Tests

44 new + updated tests cover the 4-way picker, PCDOS5 descriptor
dispatch, IBMDOSVersion helpers, legacy wire-value parsing, and the
formlogic snap behavior on every version flip.
