# dosforge v0.9.35

## Grow VHD: auto-detect boot mode + 10–100× faster file re-injection

Three Grow-tab UX fixes based on shawn@'s v0.9.34 feedback session.

### Boot mode is auto-detected (no more dropdown)

The Grow Disk form no longer asks "what boot mode is this VHD?".
The boot family is now inferred from the source VHD's root system
files at grow time:

| Root signature | Detected mode |
|---|---|
| `KERNEL.SYS` | FreeDOS |
| `IBMBIO.COM` / `IBMDOS.COM` | Compaq DOS 3.31 |
| `MSDOS.SYS` starts with `[Paths]` | MS-DOS 7.10 / Win95 OSR2 |
| `IO.SYS` + binary `MSDOS.SYS` | MS-DOS 6.22 |

Removing the dropdown also fixes the z-order bug where the boot
mode overlay was rendering underneath the size Input box and
required two clicks to bring forward.

`dosforge grow` CLI no longer requires `--boot-mode` either (still
accepted for explicit overrides, e.g. when rebuilding a corrupted
VHD whose system files don't match what you want to install).

### Re-injection is now 10–100× faster

The grow pipeline previously spawned **one `mcopy` per file** when
re-injecting the extracted source tree into the fresh VHD. On a
populated FreeDOS install (5 root files + a `\FDOS` directory with
~40 utilities), this was 47 sequential subprocess spawns and could
appear to hang for minutes on slower disks.

v0.9.35 batches root files into a single multi-source `mcopy` and
copies each top-level subdirectory recursively with `mcopy -s`.
On a 32 MiB → 128 MiB FreeDOS FAT16 grow with the full FDOS
utilities tree, this brings the inject step from N×spawn-cost down
to **2 mcopy invocations total**.

End-to-end timing on the same source VHD:

| Path | v0.9.34 | v0.9.35 |
|---|---|---|
| CLI grow + boot probe | 2.15s | **1.94s** |
| TUI grow + boot probe | 2.30s | **1.99s** |

The spinner now also reports per-batch progress (`"Step 5/8:
Re-injecting 38 root file(s)..."`, `"Step 5/8: Re-injecting
subdirectory 1/3: \GAMES\..."`) so if a single subdirectory does
turn out to be slow on a particular setup, you can see which one.

### Installer (Linux)

```bash
curl -fsSL https://github.com/flynnsbit/dosforge/releases/download/v0.9.35/dosforge-0.9.35-linux.tar.gz \
  | tar xz
./dosforge-0.9.35-linux/install.sh
```
