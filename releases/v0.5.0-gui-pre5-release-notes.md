# dosforge v0.5.0-gui-pre5 — title bar truly dark on first open

`SetWindowPos(SWP_FRAMECHANGED)` from pre4 wasn't enough on some Win11
machines — the title bar still showed the white "tab" with black boxes
around the "DosForge" caption on first open, only flipping to dark
when the window lost and regained focus.

This release does three things:

1. The GUI shell `withdraw()`s the root immediately after creation,
   builds everything, applies the DWM dark-titlebar attribute, then
   `deiconify()`s the window from `run()`. The very first frame the
   DWM composes already has the dark attribute set.
2. Re-applies the attribute and forces a non-client repaint on every
   subsequent `<Map>` event (guards against any timing edge case).
3. After setting the attribute on a visible window (e.g. theme toggle),
   resizes the window by 1px and back to force DWM to recompose the
   frame from scratch. Without this, toggling dark → light leaves the
   title bar stuck in dark mode on Win11.

No backend changes.
