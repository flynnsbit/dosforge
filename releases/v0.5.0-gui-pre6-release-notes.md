# dosforge v0.5.0-gui-pre6 — complete dosassets folder skeleton in every bundle

Both the full and lite Windows bundles now ship the COMPLETE
`dosassets/` directory skeleton — one folder per supported DOS mode
(29 in total), each containing a `readme.txt` that documents which
install media files to drop in. Extract the release and the structure
is already there; just put your install diskettes (`.img`, `.7z`,
`.vfd`, etc.) into the matching folder.

## What changed

- **Full bundle**: `dosassets/` is now moved out of `_internal/` after
  PyInstaller's COLLECT step, so the folder sits alongside
  `dosforge.exe` (matching the lite-bundle layout). Previously it was
  buried inside the Python runtime folder.
- **New folder**: `dosassets/pcdos2000/` now has a readme.txt, so the
  bundle's mode list is complete.
- **CI guard**: `scripts/check-dosassets-readmes.py` runs in the
  release workflow before PyInstaller and fails the build if any
  `dosassets/<mode>/` folder is missing its readme.
- **Smoke-test extension**: every bundle is now verified to have
  `dosassets/` at the top level with ≥25 mode folders, each with a
  readme.txt.
- **Helper**: `scripts/write-dosassets-readmes.py` generates / refreshes
  the per-mode readme stubs in bulk.

No backend or GUI changes.
