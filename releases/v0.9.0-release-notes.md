# dosforge v0.9.0

Pre-release cleanup pass to make the codebase comfortable for a
wider audience.  Removes deprecated APIs, prunes session-internal
narrative comments, and tags test-only modules.  **One breaking
change for advanced CLI users** -- see Migration below.

## Highlights

- Removed the long-deprecated `MachineTarget` enum + `MARTYPC_*`
  values (deprecated since v0.7.0; CLI flags removed in v0.7.0).
- Removed deprecated `Compaq331InstallSources` /
  `Compaq331QemuInstaller` (use `LegacyDosInstallProfile` +
  `compaq331_profile()`).
- Removed `formlogic.disabled_fields()` no-op (was always returning
  `set()` since v0.8.0).
- Pruned ~12 session-internal narrative comments (version stamps,
  Phase-XX phase tags, retrospective old-vs-new comparisons).
- Tagged 3 test-only modules (`_boot_probe.py`, `e2e_emulator.py`,
  `e2e_matrix.py`) as "not imported by runtime CLI / GUI / TUI" so
  future contributors don't second-guess deletion.

## Migration

### Removed: `dosforge.models.MachineTarget`

The `MachineTarget` enum (and its `MARTYPC_XEBEC` / `MARTYPC_XTIDE`
/ `MARTYPC_JRIDE` values) was marked "deprecated 0.7.0, remove in
v0.8.0" -- v0.9.0 finally rips it out.

External code that imported `MachineTarget` must switch to the
v0.7.0 controller-first API:

```python
# Before (v0.6.x)
from dosforge.models import MachineTarget
request = CreateRequest(..., machine_target=MachineTarget.MARTYPC_XEBEC, ...)

# After (v0.7.0+)
from dosforge.models import DiskController, BIOSVendor
request = CreateRequest(
    ...,
    disk_controller=DiskController.MFM,
    bios_drive_type=(BIOSVendor.PHOENIX, 1),
    ...
)
```

The CLI flags (`--machine-target`, `--martypc-xebec-drive-type`,
`--martypc-at-drive-type`) were already removed in v0.7.0 and are
unaffected.

### Removed: `Compaq331InstallSources` / `Compaq331QemuInstaller`

Both classes were explicitly marked "Deprecated. Use
`LegacyDosInstallProfile` + `compaq331_profile()`" in their
docstrings.  No callers anywhere in the codebase, including tests.
Switch to:

```python
from dosforge.legacy_dos_install import (
    LegacyDosInstallProfile,
    LegacyDosQemuInstaller,
    compaq331_profile,
)
```

### Removed: `formlogic.disabled_fields()`

The function returned `set()` always since v0.8.0 (kept "for
backward compat with external callers" but no caller ever
appeared).  External code that imported it should just stop
calling it -- the geometry-source picker eliminated the use case.

## Comment cleanup

Removed ~12 session-internal narrative comments across `boot.py`,
`disk.py`, `app.py`, `formlogic.py`, `models.py`,
`legacy_dos_install.py`, `fourdos_overlay.py`,
`_dos/__init__.py`, `_dos/fourdos.py`, `_boot_probe.py`,
`_gui/create_view.py`.  Patterns removed:

- `# v0.8.X:` version-stamp comments (documented WHEN, not WHY).
- `Phase 14B / 14F / 14G / 14H` session-internal phase tags
  (kept the technical meaning, dropped the tracking labels).
- `Pre-v0.8.0 returned ...` retrospective narrative.
- `# Strict mode: ... / Legacy synthesis path ...` redundant
  trailhead comments.
- `# Pre-Phase-14G un-versioned cache filenames ...` history note.
- `# ---- v0.7.0: controller-first VHD organization ----`
  migration banner.

**Kept intentionally**:
- Vintage DOS / BPB / FAT internals (real domain knowledge).
- Per-mode era authenticity context (1984 Compaq DeskPro hardware,
  IBM PC AT 1984 release date, etc.).
- Bug-fix context future maintainers need
  (e.g. the `SingleClickSelect` close-the-open-dropdown explanation).
- Citations to OS/2 Museum, WinWorldPC, IBM ServerGuide.
- Per-mode profile builder docstrings in `legacy_dos_install.py`.
