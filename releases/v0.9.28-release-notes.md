# dosforge v0.9.28

## README pass — bring user-facing docs current

The v0.7.0-era README was 20+ releases stale.  This pass refreshes
every section that drifted as wiring matured between v0.7.x and
v0.9.27.

### Updated

- **Boot mode count** "14 bootable DOS modes" → "17 bootable DOS modes"
  (matches the current `BootMode` enum; covers v0.9.10 DR-DOS 6/7 +
  v0.9.21 PCDOS2000/COMPAQ2/COMPAQ3/PCDOS3 wiring).
- **Supported boot modes table** — moved `pcdos3`, `msdos6`,
  `compaq3`, `drdos6`, `drdos7` out of the "Queued" section into
  "Wired and verified" with min-media notes.  The "Queued" section
  is now empty and was removed.
- **`pcdos` references removed** — the generic catch-all `BootMode.PCDOS`
  was deleted in v0.9.15.  Removed from the boot-modes table, MFM
  auto-detect rule, MFM controller compatibility row, dosassets
  layout, and the floppy-IMG build example (now uses `drdos6`).
- **dosassets layout** — added `compaq3`, `pcdos3`, `drdos6`,
  `drdos7`, `msdos6`, `ibm8088` directories; removed the
  deprecated `ibmpcdos401` and `msdos71/` (legacy DOS71_1S.PAK
  location); reordered alphabetically.
- **dosassets auto-discovery rule** — explicit callout at the top
  of the boot-modes section: every `dosassets/<mode>/` accepts a
  `.7z`/`.zip` archive, a raw `.img`/`.ima`/`.dsk`/`.xdf`/`.vfd`
  floppy, OR a pre-extracted directory tree, transparently.
- **`--dos-install-profile full` description** — replaced the
  one-line summary with the full v0.9.23 / v0.9.24 curation:
  what's always staged (editor / file mgmt / disk mgmt / memory /
  search-sort / scripting / mouse / sound-and-CD), what's always
  excluded (installer wizards / multi-user / DR-DOS internals /
  networking / code-page / backup / antivirus / spooler / niche).

### Added

- **"Inspect an existing VHD" section** — usage + JSON output
  shape + two-stage boot-mode inference (OEM stamp → root-system-file
  fallback).  Companion primitive for `dosforge grow`.
- **"Grow an existing VHD" section** — supported boot modes
  (compaq331/msdos622/msdos71/freedos), CLI both-form syntax,
  JSON manifest schema, cluster-band safety check, v1 limitations
  callout (custom MBR/VBR boot code is replaced).

### Files changed

- `README.md` — major rewrite of the supported-modes table, build
  examples, dosassets layout, install-profile description.  Two
  new top-level sections (`Inspect an existing VHD`, `Grow an
  existing VHD`).
- `pyproject.toml` + `src/dosforge/__init__.py` -- 0.9.27 → 0.9.28

No code changes.  All tests still pass (47 in the focused suite).
