# dosforge v0.7.8

Two improvements:

1. **Version display** in CLI / TUI / GUI.  You can now tell what
   version you're running.
2. **Dropdown close fix** — third attempt at the
   `SingleClickSelect` toggle bug.  v0.7.5 + v0.7.7 missed the
   no-blur-shift case; v0.7.8 force-closes in the Toggle handler
   when MouseDown was a no-op.

## Dropdown close fix (real, third time's the charm)

The v0.7.7 attempt assumed that clicking the chevron of an expanded
dropdown would always cause the overlay to lose focus first
(natural blur-dismiss closes the dropdown for us).  That's true
when the Select widget had to gain focus from elsewhere — but FALSE
when the Select already had focus (the focus is on the Select
widget itself, the overlay is a child).  In that case clicking the
chevron does not shift focus, no blur fires, no dismiss happens.

The "always-prevent-default + don't touch state" v0.7.7 logic
therefore left `expanded=True` in the focused-and-clicked-chevron
case → dropdown stayed open.

### v0.7.8 fix

Explicit "MouseDown just opened me" flag — same as v0.7.5 — but
applied differently:

```python
@_textual_on(SelectCurrent.Toggle)
def _single_click_toggle(self, event):
    event.stop()
    event.prevent_default()
    if self._just_opened_on_mouse_down:
        # MouseDown did the open; keep open.
        self._just_opened_on_mouse_down = False
        return
    # MouseDown was a no-op (already expanded).  Force-close --
    # works regardless of whether blur-dismiss fired or not
    # (idempotent: just sets expanded=False).
    self.expanded = False
```

Always blocks the parent's racy flip via `prevent_default()`.
Then either keeps open (if we just opened in MouseDown) or
force-closes (if MouseDown saw expanded=True and did nothing).

### Verified traces

| Scenario | Expected | Trace |
|---|---|---|
| Click closed dropdown | opens | MouseDown opens, flag=True. Toggle: prevent_default, flag clears, return. |
| Click chevron of open dropdown (focused) | closes | MouseDown sees expanded=True, no-op. Toggle: prevent_default, flag=False → `expanded=False`. |
| Click chevron of open dropdown (unfocused) | closes | MouseDown no-op. Blur-dismiss → expanded=False. Toggle: prevent_default, flag=False → `expanded=False` (idempotent no-op). |
| Click option in overlay | closes + selects | No Toggle path; parent handles UpdateSelection. |
| Click outside dropdown | closes | Blur-dismiss closes; no MouseDown on Select. |
