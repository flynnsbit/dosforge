# dosforge v0.4.0-tui-redesign-pre2 — TUI emoji fix (PRE-RELEASE)

> ⚠️ **Pre-release.** Same TUI as `pre1`, minus the emoji prefixes
> on tab labels and buttons that were rendering as boxes in
> Windows conhost.

## What's fixed

The `pre1` build used supplementary-plane emojis (U+1F300+ block)
on the 5 tab labels, the Quick Create button, the folder-picker
buttons, and the disc icon on the context bar. Windows conhost
ships with **Consolas** / **Lucida Console** by default — neither
includes the Emoji & Pictographs block, so they rendered as
`.notdef` boxes (the little squares in your screenshot).

Replaced with plain ASCII that renders cleanly in every console:

| Element | pre1 | pre2 |
|---|---|---|
| Tab 1 label | `✨  New Disk` | `New Disk` |
| Tab 2 label | `📁  Browse` | `Browse` |
| Tab 3 label | `🔧  Image Tools` | `Image Tools` |
| Tab 4 label | `🔌  Mounts` | `Mounts` |
| Tab 5 label | `⚙  Utilities` | `Utilities` |
| Browse-folder buttons | `📁` | `...` |
| Create button | `▶  Create + format VHD` | `Create + format VHD` |
| Quick Create button | `⚡ Quick Create` | `Quick Create` |
| Context bar prefix | `📀 <path>` | `image: <path>` |

## What's kept

All the BMP characters that **do** render in standard Windows
console fonts:

- `●` `○` `✓` — wizard progress markers
- `←` `→` — Back / Next arrow glyphs
- `─` — box drawing on tab borders
- `—` — em-dashes in step titles

## What's NOT changed

Everything else — wizard layout, tabs, summary card, palette,
keyboard shortcuts, auto-maximize, all backend behavior. This is
purely a glyph-compatibility fix on top of `pre1`.

## How to test

Same as `pre1` — download the Lite or Full zip, unzip, run
`dosforge.exe`. The 5 tabs should now show clean text labels with
no boxes.
