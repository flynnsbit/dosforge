# dosforge v0.6.2 — PC-DOS 7.1 utility hydration + Create-button spinner

Two user-facing improvements rolled into one Linux release.

## What's new

### 1. PC-DOS 7.1 (SGTK) FULL profile auto-hydrates from PC-DOS 2000

PC-DOS 7.10 — as shipped on IBM's ServerGuide Scripting Toolkit
1.3.07 — is intentionally slim. The SGTK readme explicitly states
*"the emm386.exe expanded memory device driver is not supported by
the ServerGuide Scripting Toolkit"*, and the same minimalism applies
to DOSSHELL, DEFRAG, BACKUP, RESTORE, POWER, UNDELETE, HELP, PRINT,
REPLACE, SHARE, INTERLNK/INTERSVR, SETVER, ANSI.SYS, EGA.SYS, and a
long tail of legacy utilities.

The PC-DOS 7.1 pre-fetcher now optionally merges those missing
utilities in from a co-located IBM PC-DOS 2000 (= PC-DOS 7.0)
install-floppy archive:

- Drop an IBM PC-DOS 2000 6-floppy 7-Zip archive into
  `dosassets/pcdos2000/` (e.g. WinWorldPC's
  `IBM PC-DOS 2000 (3.5-1.44mb).7z`).
- Run the **Fetch PC-DOS 7.1 assets** button in the TUI as usual.
- The pre-fetcher will then:
  1. Stage the 40 SGTK / PC-DOS 7.10 binaries verbatim.
  2. Extract the 6 floppy images, harvest disk01's plaintext files,
     and drive `dosbox-x` + `UNPACK2.EXE` to expand the IBM FTCOMP
     pack files (`DOS1`–`DOS4`, `SHELL1`, `SHELL2`).
  3. Merge the result into `dosassets/pcdos71/DOS/` with
     **SGTK winning every filename conflict** (case-insensitive).
- The final `C:\DOS\` on every PC-DOS 7.1 VHD goes from 40 files to
  **138 files**, picking up:
  - `EMM386.EXE`, `POWER.EXE`, `DOSSHELL.{COM,EXE,HLP}`,
    `DEFRAG.{EXE,HLP}`, `BACKUP.COM`, `RESTORE.COM`, `SETVER.EXE`,
    `UNDELETE.EXE`, `HELP.COM`, `PRINT.COM`, `REPLACE.EXE`,
    `SHARE.EXE`, `INTERLNK.EXE`, `INTERSVR.EXE`, `ASSIGN.COM`,
    `JOIN.EXE`, `ANSI.SYS`, `EGA.SYS`, `DRIVER.SYS`, and ~80 more.
  - SGTK-bytes-preserved-verbatim: `IBMBIO.COM`, `IBMDOS.COM`,
    `COMMAND.COM`, `HIMEM.SYS`, `FORMAT.COM`, `FORMAT32.COM`, etc.
- Failure modes are graceful: missing archive → SGTK install still
  succeeds, status bar reports `; PC-DOS 2000 hydration skipped: ...`.
- Cache lives under
  `~/.local/state/dosforge/cache/pcdos2000-install/pcdos2000-<sha>/DOS`,
  keyed by archive SHA-256, so updating the source archive
  automatically invalidates the cache.

**Authenticity stance:** every file remains an authentic IBM binary
(PC-DOS 7.10 OR PC-DOS 2000, never synthetic, never FreeDOS). The
`C:\DOS\` tree is a deliberate merge of two different IBM releases —
a user-approved exception to the no-cross-DOS-borrowing rule that
applies **only** to the PCDOS71 boot mode. No other boot mode borrows.

### 2. Create-button spinner + elapsed timer

`Create + format VHD` used to block the TUI silently for the entire
duration of the create-and-prepare pipeline (qemu-img create, parted,
mkfs.fat, optional boot-installer DOSBox-X/QEMU runs, mtools staging)
with zero visual indication that anything kicked off. Users could
hammer the button thinking nothing happened, or assume the app froze.

Now pressing **Create + format <VHD|IMG>**:

- Immediately disables the button so the click can't double-fire.
- Writes `Creating + formatting <VHD|IMG> <name>… (this can take a
  minute or two for VHDs with a boot install)` to the status line.
- Spawns a Textual `@work(thread=True)` worker so the event loop
  keeps pumping while the blocking pipeline runs.
- Animates a Braille spinner (`⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`) plus an
  `[elapsed in seconds]` suffix in the status line at ~10 Hz.
- On completion (success or failure) stops the spinner, re-enables
  the button, and prints either
  `✓ Created and prepared in Xs: <path>` or
  `Create failed after Xs: <error>`.

The sudo re-auth flow is preserved end-to-end (worker calls
`_run_with_sudo_reauth` which still re-prompts via zenity when
credentials expire mid-create).

## Upgrading

```bash
cd releases/v0.6.2
chmod +x install.sh
./install.sh
```

The installer handles both Arch and Ubuntu/Debian families and is safe
to re-run over an existing 0.6.1 install (it just upgrades the wheel
and rewrites `dosassets/` + the desktop entry).

To use the PC-DOS 2000 hydration, drop the WinWorldPC archive into
`dosassets/pcdos2000/` after install — it stays under your
gitignored local copy, never gets shipped.
