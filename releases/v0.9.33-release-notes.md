# dosforge v0.9.33

## Fix: Grow VHD "..." file picker

The Grow Disk tab's "..." button next to **Target VHD** had three
overlapping bugs:

1. On Linux, the zenity picker prompted **"File or Folder?"** even
   though a grow target is always a single VHD file.  Now it skips
   the radio prompt and opens directly in file-select mode.  On
   Windows the native `askopenfilename` dialog already did the right
   thing.
2. After selecting a path, the **text box stayed empty** because
   `_apply_path_picker_selection` had no branch for the
   `grow-target-input` field.  The chosen path was silently
   dropped.  Now the input is populated and a status-log entry
   confirms the selection.
3. The picker always opened in the current working directory because
   `_path_picker_start_path` had no branch for `grow-target-input`.
   Now it reads back the current input value and opens in the
   target VHD's parent directory (so re-picking from the same folder
   is one click instead of a navigation walk).

Bonus: non-file selections (e.g. a directory dragged in by accident
via the Browse-tab fallback path) are now rejected with a clear
error in the status log instead of being silently accepted.
