# dosforge v0.9.32

## TUI: move context bar below the tabs, give the wizard back its top row

The "image: (none selected)  media=vhd" context strip used to sit
*above* the tab row, stealing one row from the wizard.  Now it sits
just above the status log at the bottom of the screen, where it's
adjacent to the other persistent UI chrome.

- TUI compose order is now `Header -> TabbedContent -> #context-bar
  -> #status-current -> #status (RichLog) -> Footer`.
- No CSS changes; `#context-bar` keeps its 1-row height and color.
- All `_update_context_bar()` callers continue to work unchanged.

Net effect: the wizard / browse / tools / mounts / utilities tab
contents each gain one row of vertical space, which is most visible
on short laptop terminals where the New Disk wizard was previously
clipping the bottom of long forms.
