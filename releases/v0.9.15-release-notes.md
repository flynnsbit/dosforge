# dosforge v0.9.15

## Removed generic PC-DOS boot mode

- Removed the generic `pcdos` boot option because it was a confusing catch-all.
- Use a version-specific PC-DOS mode instead: `pcdos3`, `pcdos7`, `pcdos2000`, or `pcdos71`.
- The version-specific PC-DOS asset folders and boot flows remain intact.
